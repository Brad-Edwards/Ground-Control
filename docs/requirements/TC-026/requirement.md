# TC-026 — Comments and Discussion

## Statement

The system shall support comments on test cases, test executions, test plans, and test runs. Comments shall support @mention functionality and threaded discussions.

## Rationale

All best-of-breed tools support comments on test artifacts. TestLink and PractiTest support @mentions. Threaded discussions enable contextual collaboration without leaving the tool.
