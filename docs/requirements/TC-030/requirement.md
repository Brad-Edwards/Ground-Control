# TC-030 — Test Case Import/Export

## Statement

The system shall support importing test cases from CSV, Excel/XLSX, and XML formats with a field mapping wizard and reusable import configurations. Export shall support CSV, Excel, XML, HTML, and PDF formats with configurable column/section selection.

## Rationale

TestRail, PractiTest, TestLink, Zephyr Scale, and qTest all support CSV/Excel import and export. TestRail provides a field mapping wizard with saveable configurations. TestLink supports export to HTML, Word, Excel, OpenOffice, and PDF.
