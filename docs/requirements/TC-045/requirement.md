# TC-045 — Bulk Operations

## Statement

The system shall support bulk operations across all test entities: batch edit of multiple test cases, batch clone with field modification, bulk status transitions, bulk assignment, grid/spreadsheet view for inline editing, and find-and-replace across tests.

## Rationale

PractiTest, TestRail, qTest, and Azure Test Plans all support bulk operations. Azure Test Plans provides grid view with copy/paste and inline editing. PractiTest supports find-and-replace. Bulk operations are critical for managing large test repositories efficiently.
