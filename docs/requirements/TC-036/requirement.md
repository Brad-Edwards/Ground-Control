# TC-036 — Report Export

## Statement

The system shall support exporting reports to HTML, PDF, CSV, and Excel formats. Dashboard charts shall be embeddable and shareable via URL.

## Rationale

TestLink supports export to HTML, Word, Excel, OpenOffice, and PDF. TestRail and PractiTest support CSV export. qTest supports shareable report URLs. Report export enables offline review and stakeholder distribution.
