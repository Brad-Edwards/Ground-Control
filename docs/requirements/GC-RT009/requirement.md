# GC-RT009 — Prove production rollout, recovery, and compatibility end to end

## Statement

Ground Control shall gate production runtime rollout on cross-version contract tests, policy tests, failure recovery, audit completeness, rollback, live operations, and an explicitly accepted readiness decision.

## Rationale

This requirement is part of the private Agent Deck runtime program and is independently owned by the Ground Control control-plane repository.
