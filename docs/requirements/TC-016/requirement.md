# TC-016 — Test Environments

## Statement

The system shall support test environment definitions as first-class entities for execution context. Test runs shall be associable with specific environments. Results shall be filterable and reportable by environment. The system shall support consolidated result views across multiple environments.

## Rationale

Kiwi TCMS, Xray, Zephyr Scale, and Azure Test Plans all support environment-specific test runs. Critical for testing across staging, production-like, and different infrastructure configurations.
