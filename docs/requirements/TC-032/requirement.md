# TC-032 — Requirements Coverage Reports

## Statement

The system shall provide requirements coverage reports showing: tested vs. untested requirements, pass rate per requirement, coverage gaps identification, and a full traceability matrix (requirements to test cases to executions to defects).

## Rationale

Xray, Zephyr Scale, Azure Test Plans, PractiTest, qTest, and TestLink all provide coverage reports. The traceability matrix is a signature feature of integrated requirements+test management systems. Ground Control's existing coverage gap analysis provides a foundation.
