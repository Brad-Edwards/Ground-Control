# TC-033 — Custom Dashboards

## Statement

The system shall support customizable dashboards with configurable widgets including: pie charts, bar charts, trend lines, progress indicators, and heatmaps. Dashboards shall support multiple pivot options (by priority, configuration, tester, status, environment) and real-time updates.

## Rationale

qTest, PractiTest, Azure Test Plans, and TestRail all provide customizable dashboards. Azure Test Plans supports Power BI integration via OData. Custom dashboards enable stakeholders to monitor testing progress without running manual queries.
