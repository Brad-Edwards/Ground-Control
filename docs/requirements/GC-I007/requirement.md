# GC-I007 — Framework Coverage Gap Analysis

## Statement

The system shall provide framework-level gap analysis identifying: framework requirements with no mapped controls, controls with no evidence, controls with stale evidence, and partially covered requirements. Results shall be queryable by framework, by control, and by gap severity.

## Rationale

Compliance readiness is measured by framework coverage. Gap analysis answers "what do we still need to do for SOC 2 readiness?" — the most common question from compliance teams and the primary input for audit planning.
