# TC-027 — Notifications

## Statement

The system shall support notifications for test plan/case/run changes via email. Users shall be able to follow/watch specific entities, configure notification preferences, and receive event-driven notifications to external channels (Slack, webhooks).

## Rationale

Kiwi TCMS, TestLink, PractiTest, TestRail, and qTest Pulse all support notifications. PractiTest supports follower/watcher patterns with per-entity subscriptions. qTest Pulse supports event-driven Slack/Teams notifications.
