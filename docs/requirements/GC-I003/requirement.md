# GC-I003 — Executable Evidence Collection

## Statement

The system shall support evidence collection where evidence is executable and verifiable (test results, security scan outputs, formal proof artifacts, CI/CD pipeline results) rather than manually uploaded documents.

## Rationale

Traditional GRC relies on uploaded PDFs and screenshots as evidence. Technical GRC collects evidence from automated systems — test suites, static analyzers, formal provers — providing continuously verifiable compliance.
