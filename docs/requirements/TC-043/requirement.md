# TC-043 — Cross-Project Test Case Sharing

## Statement

The system shall support sharing and cloning test cases across projects with: cross-project cloning with field mapping, ancestor tracking for cloned tests, sync changes to update clones from source, and cross-project work item linking.

## Rationale

TestLink, PractiTest, and Kiwi TCMS support cross-project test case sharing. PractiTest tracks clone ancestry and supports sync-from-source updates. Enables reuse of common test procedures across product lines.
