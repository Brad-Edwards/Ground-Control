# TC-020 — Test Execution Status Customization

## Statement

The system shall support configurable test execution statuses beyond the default set (Pass/Fail/Blocked/Skip/Untested). Users shall be able to define custom statuses and configure status transition rules and workflows.

## Rationale

TestRail, Xray, and PractiTest support custom execution statuses. PractiTest supports configurable status workflows with transition rules and group-based restrictions. Custom statuses enable domain-specific workflows.
