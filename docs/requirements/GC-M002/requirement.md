# GC-M002 — Agent Registration

## Statement

The system shall support registering AI agents as actors with identity, capabilities, and provenance tracking, distinguishing agent-created artifacts from human-created ones in the audit trail.

## Rationale

Audit and accountability require knowing whether a requirement or traceability link was created by a human or an agent, even when both have the same permissions. Agent provenance is essential for trust.
