# TC-047 — Test Data Management

## Statement

The system shall support test data management with: shared parameter sets, dataset organization with filter trees, data-driven test execution without duplicating test cases, and import of test data from external sources (CSV/Excel).

## Rationale

Azure Test Plans, Xray, PractiTest, and Zephyr Scale all support test data management. Azure Test Plans provides shared parameter sets with Excel import. PractiTest provides dataset organization with hierarchical filter trees.
