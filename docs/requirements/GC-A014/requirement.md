# GC-A014 — Graph-Native GRC Dual API Exposure

## Statement

The system shall expose graph-native GRC entities and relationships via both REST API and MCP tools with functional parity for CRUD, traceability, graph queries, analysis, reporting, and import-export orchestration.

## Rationale

Ground Control is both a human-facing application and an agent-facing platform. Graph-native GRC capabilities must be equally available to UIs and agents or the model will fragment into separate manual and automated worlds.
