# GC-RT006 — Route runtime attention and completion events through notification policy

## Statement

Ground Control shall apply user, project, severity, quiet-hours, deduplication, and channel policy to runtime attention and completion events before delivering in-app, web-push, email, or webhook notifications.

## Rationale

This requirement is part of the private Agent Deck runtime program and is independently owned by the Ground Control control-plane repository.
