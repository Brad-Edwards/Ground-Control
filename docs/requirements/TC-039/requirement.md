# TC-039 — AI Test Case Generation

## Statement

The system shall support AI-assisted test case generation from requirements/user stories, AI-generated test step suggestions during authoring, and AI-generated automation scripts from manual test cases.

## Rationale

TestRail, Xray, PractiTest SmartFox, qTest, and Zephyr Scale all provide AI test case generation. Xray Advanced/Enterprise generates automation scripts from manual tests. AI-assisted authoring is the fastest-growing feature category in test management.
