# TC-028 — Tester Assignment and Workload

## Statement

The system shall support assigning testers to individual test cases within runs, bulk assignment, default tester assignment on test runs, personal to-do/task lists for assigned work, and tester group definitions for assignment workflows.

## Rationale

All best-of-breed tools support tester assignment. TestRail provides personal to-do lists and tester groups. Azure Test Plans supports bulk assignment and external UAT tester invitation. Workload visibility enables balanced test distribution.
