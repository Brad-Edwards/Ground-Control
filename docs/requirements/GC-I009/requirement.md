# GC-I009 — Regulatory Impact Assessment

## Statement

The system shall support assessing the impact of a regulatory change on existing controls and framework mappings, identifying: controls that need updating, new controls that need creation, framework mappings that need revision, and evidence that needs re-collection.

## Rationale

Impact assessment is the bridge between awareness and action. Agents can automatically assess which controls are affected by a regulatory change and generate remediation plans — turning regulatory change from a manual research project into an automated workflow.
