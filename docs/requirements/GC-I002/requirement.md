# GC-I002 — Compliance Framework Mapping

## Statement

The system shall support mapping requirements to compliance framework elements (SOC 2, SOX, ISO 27001, etc.), enabling gap analysis between framework requirements and the requirements that address them. Control-to-framework mapping is handled by GC-I005.

## Rationale

Compliance mapping is the bridge between engineering requirements and regulatory obligations. Gap analysis shows where additional requirements are needed for framework coverage. Control-to-framework mapping is a separate concern (GC-I005) because controls and requirements have different lifecycles and ownership.
