# GC-RT002 — Register runtime endpoints and synchronize capabilities

## Statement

Ground Control shall register authenticated runtime endpoints and maintain their stable identity, contract version, capabilities, health, capacity, and compatibility state without conflating runtime hosts with agent actors.

## Rationale

This requirement is part of the private Agent Deck runtime program and is independently owned by the Ground Control control-plane repository.
