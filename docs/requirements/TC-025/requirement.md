# TC-025 — Exploratory Testing

## Statement

The system shall support dedicated exploratory testing sessions with: mission/goals fields, session-based time tracking, note-taking during exploration, automatic bug creation from exploratory sessions, and session summary reporting.

## Rationale

Azure Test Plans, PractiTest, qTest Explorer, and TestRail all provide exploratory testing modes. Azure Test Plans provides a browser extension for capture during exploration. Session-based exploratory testing is a distinct methodology from scripted testing.
