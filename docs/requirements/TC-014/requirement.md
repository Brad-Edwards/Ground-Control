# TC-014 — Test Case Templates

## Statement

The system shall support multiple test case templates including: step-based, free-form text, exploratory session (with mission/goals), and BDD/Gherkin. Users shall be able to create custom templates and configure form layouts with field reordering. Templates shall be administerable at the project level.

## Rationale

TestRail provides multiple built-in templates plus custom template creation. PractiTest supports configurable form layouts. Template diversity accommodates different testing methodologies within a single tool.
