# TC-015 — Custom Fields

## Statement

The system shall support user-defined custom fields on test cases, test steps, test plans, test cycles, test executions, and folders. Supported field types: text, large text, numeric, dropdown/list, multi-select list, linked list, checkbox, date, and user reference. Custom fields shall be filterable, sortable, and reportable.

## Rationale

TestRail, Zephyr Scale, Xray, PractiTest, qTest, TestLink, and Kiwi TCMS all support custom fields. PractiTest supports 9 field types. Zephyr Scale supports custom fields on all entity types. Essential for adapting the tool to domain-specific workflows.
