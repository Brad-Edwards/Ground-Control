# GC-K002 — Automated Policy Evaluation

## Statement

The system shall support automated evaluation of policy-as-code artifacts against their target systems, storing evaluation results as verification evidence linked to the governing requirements.

## Rationale

Policies that are not evaluated are aspirational. Automated evaluation with results stored as evidence provides continuous assurance that policies are being enforced.
