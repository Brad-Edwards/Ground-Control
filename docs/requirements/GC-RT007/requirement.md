# GC-RT007 — Define credential-reference and execution-policy handoff

## Statement

Ground Control shall send opaque credential references and explicit execution capabilities and constraints to runtimes without receiving, persisting, or logging raw coding-harness credentials.

## Rationale

This requirement is part of the private Agent Deck runtime program and is independently owned by the Ground Control control-plane repository.
