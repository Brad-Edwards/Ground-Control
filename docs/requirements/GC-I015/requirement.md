# GC-I015 — Control Owner Assignment

## Statement

The system shall support a control ownership model where each control has a designated owner responsible for evidence collection, testing coordination, and remediation of deficiencies. Ownership changes shall be tracked in the audit trail. The system shall identify controls with no assigned owner.

## Rationale

Accountability requires ownership. Without designated control owners, evidence collection stalls, testing is nobody's responsibility, and findings have no one to remediate them. "Unowned controls" analysis prevents orphaned compliance responsibilities.
