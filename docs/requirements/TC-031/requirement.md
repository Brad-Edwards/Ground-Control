# TC-031 — Test Execution Status Reports

## Statement

The system shall provide built-in reports for: test execution status (pass/fail/blocked distribution), test run progress (completion percentage over time), defect summary linked to test results, and activity tracking reports.

## Rationale

All best-of-breed tools provide execution status reports. TestRail provides 17 standard report templates. qTest provides 60+ out-of-the-box metrics. Execution status and progress reports are the most-used reports in test management.
