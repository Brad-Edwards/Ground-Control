# GC-I016 — Control Monitoring Automation

## Statement

The system shall support automated control monitoring via scheduled evidence collection and observation ingestion linked to control test procedures or control assertions. Controls with automated monitoring shall have their effectiveness assessments updated based on collected evidence and current observations across their scoped operational assets. Agent-driven continuous control assurance shall be supported.

## Rationale

Manual periodic control testing is the weakest link in GRC. Automated monitoring transforms controls from tested quarterly to continuously observed in their operational context.
