# GC-CLD-4 — Mutation Meta-Oracle Gate

## Statement

Ground Control shall support mutation-based measurement of oracle battery strength for CLD boundaries. The gate shall define per-boundary mutation thresholds, run mutation analysis at a scope and cost appropriate to the boundary risk score, report surviving mutants as actionable evidence, and block or escalate when the battery cannot detect seeded wrongness above the configured threshold.

## Rationale

CLD treats tests and batteries as gauges that must themselves be calibrated. Mutation testing is the mechanical control against plausible, green, but vacuous tests, especially when implementation and interior tests can be generated by the same actor.
