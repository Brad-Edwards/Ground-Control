# GC-H004 — Threat Library

## Statement

The system shall support a threat library with pre-built threat templates organized by STRIDE category or comparable taxonomies, including common threat descriptions, applicable operational asset classes or boundary patterns, recommended mitigations, and relevant control patterns. The library shall support both system-provided templates and project-specific custom threats.

## Rationale

Threat modeling from scratch is slow and inconsistent. A threat library grounded in asset classes and boundary patterns helps teams and agents start from realistic scenarios rather than from generic labels disconnected from the system model.
