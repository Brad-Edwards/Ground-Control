# GC-D006 — Cross-Reference Detection

## Statement

The system shall detect requirement UID mentions (for example, GC-A001) in GitHub issue bodies, PR descriptions, and comments, and surface these as potential traceability links.

## Rationale

Developers naturally reference requirements in issue and PR descriptions. Automated detection turns these informal references into formal traceability without extra effort.
