# TC-011 — Test Case Versioning

## Statement

The system shall maintain version history for test cases with: version numbering, full change tracking, ability to view which version was executed in each test run, comparison between versions, and rollback capability.

## Rationale

Xray, Zephyr Scale, qTest, TestLink, and PractiTest all provide test case versioning. Knowing which version of a test was executed is critical for audit and regression analysis.
