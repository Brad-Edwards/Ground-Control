# TC-029 — Review and Approval Workflows

## Statement

The system shall support test case review workflows with approval gates, status-based edit locks, user group restrictions on status transitions, configurable status workflows (Draft/In Review/Approved/Obsolete), and stakeholder feedback request/response workflows.

## Rationale

Kiwi TCMS, qTest, PractiTest, and Azure Test Plans all support review/approval workflows. PractiTest supports status-based edit locks and group restrictions on transitions. Approval gates ensure test quality before execution.
