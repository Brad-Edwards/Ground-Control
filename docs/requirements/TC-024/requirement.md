# TC-024 — Test Cycles and Release Management

## Statement

The system shall support test cycles for sprint or release-based execution, release definitions with associated builds, milestones for aggregating test runs/plans, and sub-milestones for granular tracking.

## Rationale

Zephyr Scale, qTest, TestLink, Kiwi TCMS, and TestRail all support release/cycle/milestone management. Links test execution to the software delivery lifecycle.
