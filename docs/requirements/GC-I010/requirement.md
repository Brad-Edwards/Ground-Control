# GC-I010 — Regulatory Change Notification

## Statement

The system shall support notifying stakeholders of regulatory changes that affect their controls or frameworks, via in-app notifications, webhooks, or the notification system. Notifications shall include the change summary, affected controls, and recommended actions.

## Rationale

Regulatory changes require timely response. Notification ensures control owners learn about relevant changes before compliance deadlines, not during audit fieldwork.
