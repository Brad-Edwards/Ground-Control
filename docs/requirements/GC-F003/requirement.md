# GC-F003 — Verification Gap Analysis

## Statement

The system shall identify verification gaps: requirements whose target assurance level exceeds their achieved assurance level, showing where additional verification effort is needed.

## Rationale

Knowing the gap between desired and actual assurance is the primary driver for verification work. Without this analysis, teams cannot prioritize verification effort effectively.
