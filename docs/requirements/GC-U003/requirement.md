# GC-U003 — Audit Test Procedure

## Statement

The system shall support audit-specific test procedures linked to both the audit and the control being tested. Test procedures shall include sampled asset or population scope when applicable, test steps, expected results, actual results, exceptions noted, supporting observations or evidence, and test conclusion. Audit test procedures reuse the test methodology vocabulary from GC-I012 but are scoped to a specific audit engagement.

## Rationale

Audit test procedures are the unit of audit fieldwork. They document what was tested, against which operational scope, how it was tested, and what evidence supported the conclusion.
