# TC-019 — Execution Evidence and Attachments

## Statement

The system shall support attaching evidence during test execution including: file uploads, screenshots, comments/notes on individual executions, and hyperlinks. Evidence shall be stored per-execution and viewable in execution history.

## Rationale

All best-of-breed tools support evidence capture during execution. Azure Test Plans additionally supports video recording, code coverage, and system information capture. Evidence is critical for defect reproduction and audit.
