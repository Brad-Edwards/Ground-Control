# GC-F002 — Assurance Level Tracking

## Statement

The system shall track the achieved assurance level per requirement (L0 through L3 per ADR-012), based on the verification evidence available for that requirement.

## Rationale

ADR-012 defines assurance levels L0-L3. Tracking achieved levels per requirement enables gap analysis ('show me L2 requirements with only L0 verification') and drives verification prioritization.
