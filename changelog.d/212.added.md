### Added
- Cloud infrastructure evidence adapter specification (GC-S003): `domain/evidence/collection/cloud/` defines, as data over the GC-S001 `EvidenceCollectionAdapter` port, the supported providers (`CloudEvidenceProvider`: AWS, Azure, GCP), the five evidence families (`CloudEvidenceFamily`: security group configurations, encryption-at-rest status, logging configurations, backup policies, compliance scan results from AWS Config/Azure Policy/GCP Security Command Center) as canonical scope types and versioned `1.0.0` output schemas (every family an `OBSERVATION_SUMMARY` of bounded counts and external references, never raw provider exports), and the descriptor capabilities a conforming cloud collector advertises (`CloudEvidenceSpecification`). No new adapter hierarchy and no concrete provider collector. (#212)
