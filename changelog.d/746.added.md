### Added
- `GET /api/v1/analysis/grc/fair-cam-control-analytics` endpoint (GC-I017): FAIR-CAM control analytics service reads `RiskControlMapping`, `ControlEffectivenessAssessment`, and `ControlTest` rows to derive per-control domain attribution (`loss_event_control`, `variance_management_control`, `decision_support_control`), capability (design effectiveness), coverage (distinct analysis endpoints), operational performance (operating effectiveness with fresh-test count), and effect-dimension entries. Domain attribution prefers `fair_cam_domain` key in `methodologyInfluence`; falls back to `MappingControlRole` with a `limitations` entry. Supports filtering by `controlId`, `scopedImplementationId`, `riskScenarioId`, `riskRegisterRecordId`, `threatModelId`, and `domain`. Exposed via `gc_analyze` MCP tool with kind `fair_cam_control_analytics`. (#746)
