Add FAIR-CAM control analytics endpoint `GET /analysis/grc/fair-cam-control-analytics` (GC-I017). Introduces `FairCamControlDomain` (`LOSS_EVENT_CONTROL` / `VARIANCE_MANAGEMENT_CONTROL` / `DECISION_SUPPORT_CONTROL`) and extends `ControlEffectivenessAssessment` with an optional `fair_cam_control_domain` column (Flyway V131 + audit V132). The endpoint reports per-control capability / coverage / operational-performance dimensions, each with its own `scale`/`units`, beside the GC-I013 `ControlEffectivenessRating` rather than absorbing it. Exposed via the consolidated `gc_analyze` MCP tool with the new `fair_cam_control_analytics` kind.
