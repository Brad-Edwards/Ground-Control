### Added

- **NIST Risk Response & Ongoing Monitoring (GC-T015)**: Extended
  `TreatmentPlan` with three new fields:
  - `riskAssessmentResultId`—optional FK to the originating
    `RiskAssessmentResult`, validated through
    `GraphTargetResolverService.validateRiskAssessmentResultTarget` so a
    cross-project result UUID is rejected at the service boundary (closes
    the GC-T004/C8 cross-project bug class for this new relationship).
  - `monitoredRiskFactors`—typed list of `MonitoredRiskFactor` records
    capturing the label, the NIST §3.4 change category being watched, and
    the per-factor ISO-8601 re-check cadence.
  - `updateCadence`—plan-level ISO-8601 duration for the heartbeat at
    which the whole treatment plan is re-evaluated.
- Reassessment trigger surfaces extended (per GC-T015): the typed
  `ReassessmentTriggerCategory` enum now covers threat / vulnerability /
  predisposing-condition / observation / topology / environment changes
  alongside the existing treatment / asset / control surfaces.
