Add FAIR v3.0 quantitative risk analysis endpoint `GET /analysis/grc/fair-quantitative` (GC-T011). Returns a methodology-attributed envelope with LEF / LM / ALE three-point summaries and Monte Carlo percentile outputs (p5/p10/p50/p90/p95/p99) computed from a seeded deterministic RNG so reproducibility is auditable. Monetary outputs carry explicit `currency`, `scale`, and `units`; FAIR factor maps inside `inputs` pass through verbatim from the persisted methodology-defined keys. Exposed via the consolidated `gc_analyze` MCP tool with the new `fair_analysis` kind.
