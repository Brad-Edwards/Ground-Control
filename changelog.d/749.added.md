### Added
- Control and Assurance Workspace (GC-Q011): read-only `GET /api/v1/controls/workspace` endpoint and a React workspace page composing controls with their scoped implementations, control-test summary and history, latest effectiveness assessment, risk-control mapping count, exceptions (findings linked to the control), an evidence-freshness staleness indicator, and per-owner work queues with attention flags. Filterable by status, function, owner, asset, and freshness window. Exposed to agents via the `gc_control_workspace` MCP tool. A shared `FreshnessBadge` component now renders evidence freshness consistently across the GRC workspaces. (#749)
