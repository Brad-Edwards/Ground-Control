Add continuous compliance monitoring for GC-I004. Evidence artifacts now
carry optional `expiresAt` and `validityWindowDays` fields; the sweep job
NEVER mutates artifact rows so append-only semantics are preserved. A new
`ComplianceDriftDetectorService` listens synchronously to
`ControlStateChangedEvent` and `EvidenceExpiryEvent` and writes append-only
`compliance_drift_event` rows. A new scheduled `EvidenceExpirySweepJob`
(opt-in via `groundcontrol.compliance.evidence-expiry-enabled=true`) lives
alongside `AuditRetentionJob`. The new `/api/v1/compliance-drift-events`
REST surface exposes list, get, acknowledge, and liveness; reads route
through `gc_query` on the MCP side (no new top-level tool because drift
events are detector-emitted, not agent-published). Liveness telemetry
surfaces `lastDetectedAt`, `lastSweepAt`, and the unacknowledged-event
count so a stalled monitor cannot silently report 'compliant'. ADR-045 §8
amendment plus `architecture/notes/continuous-compliance-monitoring-preflight.md`.
