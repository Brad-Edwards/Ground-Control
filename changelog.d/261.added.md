### Added

- **Risk Assessment Campaign workflow (GC-T006)**: New
  `RiskAssessmentCampaign` aggregate with an explicit
  `PLANNING → IDENTIFICATION → ANALYSIS → EVALUATION → TREATMENT → CLOSED`
  phase state machine (L2-contracted on the aggregate). The methodology
  profile binding becomes immutable once the campaign reaches `EVALUATION`—re-running
  with a different methodology is a new campaign, preserving
  audit trail. Campaigns optionally bind a `RiskAppetiteProfile` for the
  evaluation phase to drive automated tolerance labelling.
  CRUD lives at `/api/v1/risk-assessment-campaigns`; phase transitions go
  through `PUT /{id}/phase`.
- New `CampaignPhase` enum mirrored at the frontend
  (`CAMPAIGN_PHASES`) and MCP boundaries per ADR-034.
