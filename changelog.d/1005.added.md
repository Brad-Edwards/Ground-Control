### Added - Methodology source coverage gate (GC-RSCH-F006): `ResearchRunService` now requires an active methodology selection with all required sources in `READ` state before accepting a `METHODOLOGY_REQUIREMENTS` artifact. The required-source set is derived from a new backend-owned, validated-on-load method-profile catalog (`research/methodology-catalog.yaml`, ADR-077) - the single source of truth that the lit-review skill catalog mirrors under a `make policy` drift check - rather than being supplied by the caller; `select_methodology` now takes only `method_key` and rejects unknown methods. New API endpoints manage selections and sources and expose the catalog (`GET /methodology/catalog`, `POST/GET /methodology/selection`, `POST/PATCH/GET /methodology/sources`). MCP `gc_research_run` exposes the actions: `list_methodology_catalog`, `select_methodology`, `get_methodology_selection`, `record_methodology_source`, `update_methodology_source_state`, `list_methodology_sources`.
