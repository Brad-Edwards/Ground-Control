### Added - Architecture-as-code registry (GC-CLD-2)

`architecture/registry/module-graph.json` is now the single data source for
CLD structural boundaries: modules, allowed dependency edges, ownership, lock
levels, risk scores, and architecture-model projection metadata. Backend
`RegistryBoundaryArchitectureTest` (ArchUnit) and the `run_module_graph_boundary_check`
policy check (frontend + MCP import scan) both read this one registry, so a
dependency edge not declared in it fails CI in the layer that introduced it.
Because the registry lives under the design-authority-protected
`architecture/registry/**` selector, lock-level and boundary changes require the
separation-of-powers approval marker.
