### Added
- Evidence and State Explorer (GC-Q012): read-only `GET /api/v1/evidence-artifacts/explorer` endpoint and a React page surfacing evidence artifacts and observations annotated with freshness state, provenance (source refs, observation source/confidence/evidence reference), affected assets, and downstream finding impact, plus a freshness counts roll-up. Freshness reuses the GC-L007 `EvidenceFreshnessAnalysisService` rather than re-deriving it. Filterable by asset, evidence type, supersession, and freshness window. Exposed to agents via the `gc_evidence_explorer` MCP tool. (#750)
